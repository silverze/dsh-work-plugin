# @dsh-work-plugin/host

Host plugin of the DSH Work bundle: opens the `work` storage domain, provides
`ctx.workTasks` and the artifact library, registers the `work_*` tools and the
`/work` command, and binds scheduled runs to work tasks.

Installed as part of the `@dsh-work-plugin/bundle` bundle; see the repository README
for the product overview.

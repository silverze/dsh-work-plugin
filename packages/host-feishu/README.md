# @dsh-work-plugin/feishu

Host plugin of the DSH Work bundle: Feishu (Lark) OAuth, OpenAPI tools for
docs, sheets, wiki, messaging and sharing, write approvals, and scheduled-run
notifications. The user access token comes from the environment variable named
by the row's `accessTokenEnv` config.

Installed as part of the `@dsh-work-plugin/bundle` bundle.

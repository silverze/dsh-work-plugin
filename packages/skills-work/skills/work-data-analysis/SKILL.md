# 数据分析

目标：结论可复现、数字可核对、图表能直接放进汇报。

## 输入

确认：业务问题、数据文件、指标口径、时间范围、维度、期望输出（xlsx/docx/图表）。口径不清时先问，不要自己发明。

## 流程

1. **体检**：行列数、字段类型、缺失值、重复、异常值、时间范围；把发现写进 `data-quality.md`。
2. **清洗**：明确规则（去重、缺失处理、单位统一、异常值处理），保存脚本到成果目录，保证可复现。
3. **计算**：先定义指标，再计算；做总量/分组合计校验，确保能对上。
4. **分析**：同比/环比、结构、趋势、异常点；每个结论给证据。
5. **可视化**：2–4 张图，标题写结论，坐标轴带单位，标注数据来源与时间。
6. **交付**：`analysis.xlsx`（含图表与明细）+ `analysis.md` 或 `analysis.docx`；用 `present` 声明。

## 质量门槛

- 不静默删除异常值；说明处理方式和影响。
- 图表不误导：坐标轴从 0 开始（除非有理由）、不截断、不双轴混淆。
- 区分“相关”与“因果”；没有证据时只写假设。
- 单位、口径、时间范围在图表和正文中一致。
- 关键数字至少用一种独立方式复核（合计/抽样/交叉表）。

## 输出结构

1. 结论摘要（3 条）
2. 数据与口径
3. 关键发现（图 + 解释）
4. 异常与原因假设
5. 建议动作
6. 局限与下一步

## 边界

- 原始文件只读；清洗结果另存。
- 不把敏感明细写进可分享报告；聚合或脱敏。
- 不连接外部数据库/BI，除非用户明确授权并配置连接器。
